# Словарь русских пятибуквенных слов v2

## Состав

- `ru5.json`: **2083 допустимых слова**, **1758 слов для ответа**.
- По сравнению с v1 добавлены **83 допустимых слова** и **558 ответов**.
  Старые допустимые слова и ответы не удалены. Ответы входят в допустимый
  набор, а не прибавляются к нему.
- Русский алфавит, ровно пять букв; NFC, верхний регистр, `Ё → Е`.
- Более узкий набор ответов нужен, чтобы не выбирать редкие допустимые слова
  в качестве ежедневной загадки. Пользовательского режима «загадай другу» нет.
- При запуске игры используются только готовые JSON-данные: `pymorphy3` и
  `wordfreq` не устанавливаются в окружение бота и не загружаются сервером игры.

Частоты `wordfreq` отражают корпусный снимок примерно до 2021 года. Это

PyPI и встроены в поле `sources` и сборщик. Для воспроизводимой подготовки
сохранён `build-tools.lock` с хешами использованного набора инструментов.

## Правила отбора

Полные ручные правила находятся в `selection_rules.json`.

1. Рассматриваются частотные кандидаты и отдельный список знакомых бытовых
   слов, чья корпусная частота ниже порога.
2. Требуется известный словарный разбор `NOUN + sing + nomn` и совпадение
   начальной формы с введённым словом после игровой нормализации.
3. Отсекаются разборы имён, фамилий, отчеств, географических и организационных
   названий, сокращений и некоторые ненормативные/устаревшие формы.
4. Если доминирует именной разбор, кандидат отбрасывается. Небольшой явный
   список сохраняет обычные омонимы: например, «МАРКА», «МОРОЗ», «ЛИЛИЯ».
5. Отдельные ручные исключения убирают замеченные имена/бренды, неоднозначные
   формы и грубую лексику, которую морфология пропускает.
6. Для допустимого набора используется ориентир Zipf ≥ 2.3, для ответов ≥ 3.0.
   Отмеченные бытовые кандидаты допускаются ниже порога. Затем частотный
   набор больше не обрезается до искусственного количества. Список ответов
   остаётся его подмножеством.
7. В v2 частотный поиск расширен с 300 000 до 500 000 кандидатов без снижения
   порогов. Явный просмотренный список знакомых слов расширен с 182 до 740:
   например, «БУЛКА», «КОФТА», «НОРКА», «ШМЕЛЬ», «БИДОН», «КОПНА».
   Именно из него взяты все новые ответы и все новые допустимые слова.
   Отдельно исключены 37 дополнительных кандидатов, которые не прошли
   качественный отбор: редкости, специальные термины и грубые разговорные слова.

## Ограничения качества

**Это автоматический отбор с частичной ручной проверкой, не полная экспертная
вычитка всех 2083 слов.** Морфологический разбор и частота бывают неоднозначны.
Наличие слова в словаре не означает, что оно одинаково знакомо всем игрокам.
Для дальнейшей настройки нужно править явные правила и пересобирать словник,
а не тайно менять JSON без обновления версии/контрольных сумм.

Число 5000 не является целью, ради которой можно ослабить требования к словам.
Набор v2 не доказывает, что в русском языке больше нет подходящих слов: это
зафиксированный результат данного источника, фильтров и ручной проверки.

Например, собственное имя «ГЕНРИ» совпадает с названием единицы измерения;
такие кандидаты явно исключены, чтобы частота имени не делала слово ответом.
В то же время обычные омонимы «РОМАН», «МАРКА» и «МОРОЗ» допускаются как
существительные в их нарицательных значениях.

## Совместимость сохранений

Исходный `ru5-opencorpora-wordfreq-v1-165050f1e2b8` сохранён без изменений
в `archive/ru5-opencorpora-wordfreq-v1-165050f1e2b8.json`. Его 1200 ответов
нельзя пересортировать или заменить при восстановлении старой партии:
новые ответы меняют прежнюю последовательность. Архив нужен серверной
миграции, чтобы сохранить старый ответ, попытки, раскраску и статистику.

## Воспроизведение на ноутбуке

Проверенный набор инструментов: Windows x64, Python 3.10. Основные wheel-файлы
с данными и инструментами платформонезависимы; lock также фиксирует Windows-
сборки вспомогательных пакетов. Для другой платформы может потребоваться
отдельный lock, но версии и хеши основных источников должны сохраниться.

Не устанавливайте инструменты в окружение бота. Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pip download --require-hashes --only-binary=:all: --dest .test-data/wordli-dictionary-downloads -r prototypes/wordli/data/build-tools.lock
.\.venv\Scripts\python.exe -m pip install --no-index --find-links .test-data/wordli-dictionary-downloads --require-hashes --target .test-data/wordli-dictionary-tools -r prototypes/wordli/data/build-tools.lock
.\.venv\Scripts\python.exe -B testing/prepare_wordli_dictionary.py
```

Если в Windows нужен дополнительный доверенный CA-файл, используйте
`--cert .tools/windows-ca.pem`. Проверку TLS отключать нельзя.

Сборщик не обращается к сети, проверяет версии и SHA-256 основных wheel-файлов,
не читает `.env`, не импортирует модули бота и не использует БД. Результат
пишется в `ru5.json`; числовой аудит кандидатов можно вывести только в
игнорируемую `.test-data` через `--audit-output`.
